# Hello Kitty — магазин

Простой веб-магазин на Django: каталог с сортировкой, регистрация и вход, корзина, заказы.
Визуал — временные заглушки (`static/style.css`, `static/img/`), финальный делает дизайнер.

## Запуск

```bash
python -m venv venv
source venv/bin/activate
pip install -r req.txt
python manage.py migrate
python manage.py seed        # тестовые товары, пользователи и заказы
python manage.py runserver 0.0.0.0:12312
```

Сайт: http://127.0.0.1:12312/, админка: http://127.0.0.1:12312/admin/ (товары и заказы).

> `DEBUG = False`, поэтому после изменений в `static/` выполните `python manage.py collectstatic` и перезапустите сервер.

## Аккаунты

| Логин | Пароль | Роль |
|---|---|---|
| `admin` | `admin123` | суперпользователь, полный доступ |
| `manager` | `manager123` | админ: товары и обычные пользователи, без прав выдавать админку |
| `anna`, `maria`, `kate` | `123456` | покупатели с заказами (создаются командой `seed`) |

Сменить пароль: `python manage.py changepassword admin`.

## Ограничения

- Не больше 99 шт. одного товара в корзине.
- Цена товара от 0,01 до 999 999,99 ₽, описание до 1000 символов.
- Пароль от 6 символов, логин и email уникальны без учёта регистра.
- 5 неудачных попыток входа подряд — блокировка на 5 минут.
- Обычный админ не может редактировать суперпользователя и выдавать права админа.

## Страницы

| Адрес | Что |
|---|---|
| `/` | Главная: каталог с сортировкой |
| `/cart/` | Корзина и оформление заказа (нужен вход) |
| `/profile/` | Профиль и история заказов |
| `/login/`, `/signup/` | Вход и регистрация |
| `/panel/` | Админ-панель: CRUD товаров и пользователей (только для админов) |

## Структура

```text
conf/            настройки и корневые маршруты
web/
  models.py      Product, CartItem, Order, OrderItem
  views.py       главная, корзина, профиль, вход/регистрация
  panel.py       админ-панель
  forms.py       формы регистрации, профиля, товара, пользователя
  urls.py        маршруты сайта
templates/       HTML-шаблоны без визуала
static/          стили и картинки-заглушки
```
